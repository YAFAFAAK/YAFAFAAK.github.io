Brooks Case Collector

为个人价格行为研究收集公开市场案例和行情数据，并将研究资料归档到本人授权的 Google Drive。

功能与使用范围

本应用是账号所有者自用的资料收集与整理工具，目前不向公众提供注册或云盘托管服务。

  • 收集公开市场复盘文章、公开图表及行情数据，保留来源和采集时间。
  • 按日期和资料类型将文件归档到指定 Google Drive 项目目录。
  • 生成案例与行情索引；项目代码和少量索引元数据由私有 GitHub 仓库管理。

为什么需要 Google Drive 授权？

应用通过 rclone 和 Google Drive API 读取既有项目资料、上传新资料并更新派生索引。因为项目目录中已有其他工具创建的文件，本配置申请 https://www.googleapis.com/auth/drive 权限。

此权限可覆盖账号中的广泛 Drive 文件。程序按配置的项目根目录和文件标识操作；目录配置本身不是 Google 提供的文件夹级权限隔离。

每日定时采集程序本身不调用语言模型，也不会自动将云盘文件内容发送给模型服务。

隐私与联系

请阅读隐私政策，了解数据使用、保留与撤销授权的方法。本人可通过 Google OAuth 授权页面所列支持邮箱联系应用维护者；公开开发者信息见页脚 GitHub 链接。

本工具独立开发，与 Al Brooks、Google、Yahoo 或其关联机构不存在官方隶属关系。此网站只公开应用说明与隐私政策。
