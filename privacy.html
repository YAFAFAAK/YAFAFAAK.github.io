隐私政策

适用应用：Brooks Case Collector · 更新日期：2026 年 10 月 18 日

本政策说明账号所有者自用的 Brooks Case Collector 如何通过 Google Drive API 处理研究项目资料。此应用目前不提供公众账号注册。

1. 访问和处理哪些数据

经本人授权后，应用访问配置的 Google Drive 项目目录及其相关文件，包括文件内容、名称、文件标识、所在目录、大小和核验所需元数据。操作用于读取既有资料、上传采集文件和更新派生索引。应用不以本任务为由读取 Gmail、通讯录或日历。

本配置申请 drive 权限，以访问已经由其他工具创建的项目文件。该 OAuth 权限本身可访问更广泛的 Drive 文件；程序通过配置限制日常操作范围，并不声称获得了 Google 文件夹级独立授权。

2. 数据用途与共享

数据仅用于账号所有者的资料归档、检索、完整性核验及故障恢复。应用不出售 Google 用户数据，不将其用于广告画像，也不使用 Google 用户数据训练通用人工智能或机器学习模型。

每日定时采集程序本身不调用语言模型，也不自动向模型服务发送云盘文件内容。用户日后主动进行的其他研究或 AI 分析需另行决定，并遵循相应工具的数据政策。

原始研究资料存储于本人 Google Drive；代码及少量索引元数据存于本人私有 GitHub 仓库；本人 VPS 保留运行日志、状态及必要临时文件。Google、GitHub 和 VPS 服务商按各自服务条款处理相应服务数据。应用不会因这些存储操作主动公开研究资料。

3. 凭证和访问控制

OAuth 凭证用于经授权访问 Google Drive，保存在本人 VPS 的受限配置文件中，不应提交到 GitHub 或放入公开页面。应用使用服务提供方的 HTTPS 接口进行网络传输。维护者需保护 VPS 登录和凭证访问权限。

4. 保留与删除

云盘中的归档资料持续保留，直到本人主动删除。成功归档并确认发布后，采集器清理该批次原始临时文件，保留少量状态、元数据缓存及日志；失败批次会保留用于恢复。

本人可分别删除 Google Drive 资料、GitHub 索引和 VPS 缓存。GitHub 历史提交及服务商备份可能仍按其保留机制存在，删除当前文件不会自动清除所有历史版本。采集器不会自动清理历史云盘原件。

5. 撤销授权和停止运行

本人可在 Google 账号的第三方连接设置中撤销应用访问权限，并停止 VPS 上的采集服务及定时器。撤销授权会阻止后续授权访问，但不会自动删除已经归档的文件。

6. 联系与政策更新

支持联系渠道为 Google OAuth 授权页面所列应用支持邮箱；公开开发者信息见 GitHub 个人主页。如应用用途、处理范围或存储方式改变，将相应更新本页面。
